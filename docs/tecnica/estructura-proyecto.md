# Estructura del Proyecto

El repositorio está dividido en las siguientes carpetas principales:
* `backend/`: Contiene la API, lógica y base de datos.
* `ui/`: interfaz NiceGUI implementada (13 rutas, cliente `httpx`, pruebas en `ui/tests/`).
* `docs/`: Documentación del proyecto.

## Ramas y Equipos
* `main`: Versión estable.
* `desarrollo`: Integración de todos los equipos.
* `postgres`: Equipo 1 (Base de datos).
* `facturacion`: Equipo 2 (Lógica de facturación).
* `catalogo`: Equipo 3 (Catálogo y pedidos).
* `api`: Equipo 4 (API y seguridad).
* `ui-facturacion`: Equipo 5 (Interfaz de facturación).
* `ui-catalogo`: Equipo 6 (Interfaz de catálogo).
* `documentacion`: Miriam y Odelkis.
